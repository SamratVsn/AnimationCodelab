# Animation Codelab

A Jetpack Compose project exploring Android animation APIs, built while working through Android's animation codelab material.

## About

This project is focused on learning and practicing animations in Jetpack Compose — things like state-based animations, transitions, and animation composables. It's a hands-on codelab/practice project rather than a standalone app.

## Built With

- Kotlin
- Jetpack Compose
- Android SDK
- Gradle

## Status

Practice/learning project.
